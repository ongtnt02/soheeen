# 소희엔 — 광고 운영 대행 홈페이지 (다중 페이지 v2)

LMS 대량 고객 메시지 광고와 메타(Meta) 광고를 기획·총괄 운영하는 광고대행사 **소희엔**의 홈페이지입니다.
원페이지 초안(v1, `sites/ad-agency/`)을 5개 페이지로 나눈 정식 다중 페이지 버전입니다.

- 외부 라이브러리·웹폰트·CDN·이미지 파일을 쓰지 않습니다. **인터넷 없이 파일만 열어도 그대로 보입니다.**
- 아이콘은 모두 인라인 SVG, 폰트는 시스템 폰트입니다.
- 서버·데이터베이스가 필요 없는 정적 사이트라 GitHub Pages·Netlify·Vercel 어디에나 올릴 수 있습니다.

## 2. 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | **홈** — 히어로, 컨트롤타워 운영 구조, 핵심 강점 3가지, 주력 매체(LMS·메타) 요약, 문의 CTA |

| `services.html` | **서비스 안내** — LMS 대량 고객 메시지 광고, 메타(Meta) 퍼포먼스 광고, 실행 파트너 총괄·성과 리포팅 |
| `process.html` | **진행 과정** — 5단계(상담·목표 진단 → 매체·타겟 설계 → 파트너 매칭·검수 → 집행·운영 → 리포트·최적화) |

| `styles.css` | 5개 페이지가 함께 쓰는 공통 스타일 (색·여백·반응형·인쇄) |

| `preview-home-mobile.png` | 홈 화면 폰(390px) 전체 캡처 |
| `preview-services-desktop.png` | 서비스 화면 PC(1440px) 전체 캡처 |
| `preview-live-github-pages.png` | 실제 배포된 사이트(GitHub Pages) 홈 화면 캡처 |

> 미리보기 PNG는 확인용이며, GitHub에는 올리지 않았습니다(배포 용량·구성 정리). 이 폴더와 구글 드라이브에는 있습니다.

### 페이지 연결 구조

```
index.html (홈)
 ├─ about.html      (회사 소개)
 ├─ services.html   (서비스, #lms · #meta · #ops 앵커)
 ├─ process.html    (진행 과정)
 └─ contact.html    (문의)
```

모든 페이지 상단 메뉴·하단 메뉴에 5개 페이지가 서로 연결되어 있고, 현재 페이지는 메뉴에 강조 표시됩니다.

## 3. 디자인 톤

- 밝은 화이트 배경 + 네이비/블루 포인트(B2B 신뢰감 우선), 본문은 진한 회색.
- 어두운 남색 띠(CTA 밴드)와 다크 푸터로 마무리.
- 모바일: 860px 이하에서 햄버거 메뉴, 620px 이하에서 1열 카드로 전환.

색을 바꾸려면 `styles.css` 맨 위 `:root` 값만 수정하면 5개 페이지에 동시에 적용됩니다.

```css
--accent: #2456f0;   /* 버튼·포인트 색 */
--ink: #0f1b2d;      /* 제목 색 */
--tint: #f5f7fb;     /* 옅은 배경 */
--dark: #0d1626;     /* 어두운 배경 */
```

## 5. 내용에 대한 원칙 (지어내지 않은 것)

- **실적·수치·고객사 로고·수상·직원 수를 넣지 않았습니다.** 실제 자료가 없기 때문입니다. 자료가 생기면 '실적' 섹션을 추가할 수 있습니다.
- **제휴사 이름·단가·최소 발송 수량을 넣지 않았습니다.** services.html에는 "제휴 매체와 캠페인 조건에 따라 달라지며 상담에서 안내한다"는 문장으로만 적었습니다.
- **LMS**는 '장문 문자 메시지(Long Message Service)'로, MMS·RCS와 함께 문자 광고의 형태로 설명했습니다.
- **타겟팅 데이터 출처**는 "통신사·금융사(카드 결제 데이터)·포인트앱 등에서 제공되는 빅데이터"로 적었고, 실제 사용 가능한 세그먼트는 캠페인 조건에 따라 확인이 필요하다는 단서를 함께 넣었습니다.
- 상담이 무료라든가, 특정 기간 내 착수 같은 **확인되지 않은 약속은 쓰지 않았습니다.**
